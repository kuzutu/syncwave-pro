# SyncWave Pro

Free, fully offline DJ app for macOS and Windows: library cleanup, next-track suggestions, set builder and a two-deck player with beat-locked sync and Auto DJ.

**Download:** see the [download page](https://kuzutu.github.io/syncwave-pro/) or the [latest release](https://github.com/kuzutu/syncwave-pro/releases/latest).

| File | For |
|---|---|
| `SyncWave-Pro-2.4.0-mac-AppleSilicon.zip` | Macs with M1/M2/M3/M4 chips |
| `SyncWave-Pro-2.4.0-mac-Intel.zip` | Intel Macs |
| `SyncWave-Pro-2.4.0-Windows-Setup.exe` | Windows 10/11 (64-bit), installer |
| `SyncWave-Pro-2.4.0-Windows-Portable.zip` | Windows 10/11 (64-bit), no install |

The app is not signed by Apple or Microsoft; the first launch needs one extra click. Installation steps are on the download page.

SyncWave Pro never connects to the internet. See [LICENSE.txt](LICENSE.txt) for the terms of use.
